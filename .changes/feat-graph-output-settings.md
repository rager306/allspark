- The `graph` tool's output, pack and search windows are settings now: `graph.outputMaxBytes` caps one rendered `architecture` report (default 50 KiB, and the cut is named in the answer), `graph.packSymbols` sets a `context` pack's default budget, and `graph.searchLimit` sets a bare `search`'s default limit. A call's own `limit` still wins; `0` or an unset key keeps the compiled default, and a value above a model-facing ceiling is clamped rather than honoured.
