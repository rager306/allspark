## Two behaviours that look like bugs and are not

1. **The installer runs the launcher once** as its own `--version` verification
   (`install-rust.sh`, the "verify: the launcher must answer --version" block).
   The launcher creates `$ALLSPARK_HOME` and its `run/` directory, so
   `$HOME/.allspark-home/run` appears even when the prefix is `/opt/allspark`.
   A test asserting "the default home must not exist" is wrong, not the code.
2. **`.dirty` in `--version`**: `build.rs` appends it when the tree is dirty. The
   artifacts verified here were built while docs/workflow edits were uncommitted.

## Gotchas for the next agent

- `git push --dry-run` **runs the pre-push hook**. Wrapping it in `timeout`
  orphans `clippy` and it keeps the build-directory lock; two dry-runs gave two
  contending clippy runs and a blocked second one. Run the gate explicitly
  (`cargo fmt --all --check` + `cargo clippy --workspace --all-targets -- -D warnings`),
  then push once.
- `env_clear()` on any probe that spawns `sh`/`cargo`: a live session exports
  `PRIME_AGENT_DAEMON_SOCKET` and the installer's layout logic reads it.
- Never run `install-rust.sh` from inside a session (AGENTS.md). The container
  recipe in `readme-fork.md` §9 is the sanctioned path.
